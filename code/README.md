# Code

`bitcoin_forecasting.py` is the publication-oriented full-data forecasting program. It evaluates eight direct horizons (15D, 1M, 2M, 3M, 6M, 12M, 24M, 36M) with expanding-window walk-forward forecasting and a heterogeneous panel of benchmark, statistical, neural, hybrid, and Adaptive Ensemble models.

The GitHub copy uses a repository-relative project directory rather than a machine-specific Windows path, while preserving the modeling configuration.
