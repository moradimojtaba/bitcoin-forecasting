# Data

The primary modeling file for the reported experiment is:

`data/processed/bitcoin_modeling_dataset.csv`

The audit metadata records **4,761 observations covering 2011-05-14 through 2024-05-25** and the SHA-256 fingerprint of the exact input file.

**Important:** the exact frozen CSV was not available in the current working file set when this GitHub package was prepared, so it is intentionally not fabricated or substituted. Before publishing the repository as the definitive replication archive, place the exact frozen CSV at the path above and verify its SHA-256 hash against `results/metadata_V6_2.json`.

Do not silently replace the frozen dataset with a newer download if the goal is exact reproduction of the reported results. A newer dataset constitutes a new empirical run.
